# 接码注册功能开发文档（d1jiema 平台对接）

> 版本：v1.0 草案
> 目标：为 Trae Work 助手新增「注册账号」一级导航页，对接 d1jiema 接码平台 API，
> 实现取号 → 收验证码 → 释放/拉黑的完整注册辅助流程。

---

## 1. 功能概述

用户在注册 Trae 账号时需要手机号接收验证码。本功能对接 d1jiema 接码平台，
在软件内完成：获取临时手机号 → 轮询收取短信验证码 → 复制验证码 → 释放或拉黑号码。

### 1.1 功能清单（按用户需求）

| 模块 | 功能点 | 实现方式 |
|---|---|---|
| 设置 | 短信关键词（默认 `Trae`） | `getPhone`/`getMsg` 的 `keyWord` 参数 |
| 设置 | 运营商选择：虚拟卡 / 实体卡 / 全部 | `cardType` 参数（实卡/虚卡/全部） |
| 设置 | 归属地：全部 | `province` 留空 |
| 手机号 | 获取手机号（随机取号） | `getPhone` |
| 手机号 | 指定手机号 | `getPhone?phone=xxx` |
| 手机号 | 释放手机号 | `release` |
| 手机号 | 拉黑手机号 | `block` |
| 手机号 | 复制手机号 | 前端 `navigator.clipboard` |
| 短信 | 收取短信（自动轮询） | `getMsg`（3 秒间隔轮询，最多 120 秒） |
| 短信 | 发送短信 | `send` |
| 短信 | 查看短信记录 | `queryUsed`（限频 1 次/分钟） |
| 短信 | 浏览短信库 | 同上，本地缓存展示 |
| 账号 | Token 配置 | 设置页粘贴 Token（网页版创建） |
| 账号 | 余额查询 | `leftAmount` |
| 账号 | 充值入口 / 注册入口 | 外链跳转 d1jiema 官网 |

### 1.2 明确不做

- 账号密码直接登录：d1jiema 未公开密码登录 API，仅支持网页版创建 Token。
  用户首次使用需在官网注册并创建 Token，粘贴到软件设置中（Token 永久有效）。
- 自动注册 Trae 账号：本功能只辅助取号收码，注册动作由用户在 Trae 客户端完成。

## 2. 安全设计（重要）

**Token 绝不进入代码仓库。**

- Token 由每个用户运行时自行填入，保存于本地数据目录的 `settings.json`
  （Windows: `%APPDATA%/Trae Work 助手/`；macOS: `~/Library/Application Support/Trae Work 助手/`）。
- `.gitignore` 已排除数据目录；仓库代码中只存在默认空值。
- 日志输出时对 Token 做脱敏（只显示前 4 位 + `****`）。
- Token 仅在 Rust 后端拼接请求，**不下发到前端渲染的 DOM**（设置页回显同样脱敏）。

因此仓库保持 Public 是安全的：他人下载软件后必须使用自己的 Token。
同时公开仓库可享受 GitHub Actions macOS 构建完全免费（私有仓库 macOS runner
按 10 倍计费，免费额度仅约 10 次构建/月）。

## 3. d1jiema API 对接明细

- 基础地址：`https://api.d1jiema.com/zc/data.php`
- 方式：GET，UTF-8，汉字参数需 URL 编码
- 通用返回：成功返回内容文本；失败返回 `ERROR:错误信息`

| code | 功能 | 关键参数 | 成功返回 | 备注 |
|---|---|---|---|---|
| `leftAmount` | 查余额 | token | 余额数字 | 启动时拉取一次 |
| `getPhone` | 取号 | keyWord(建议)、phone(可选指定)、province(可选)、cardType(实卡/虚卡/全部) | 手机号 | keyWord 建议必填，否则可能收到被屏蔽短信 |
| `getMsg` | 收短信 | phone(必填)、keyWord(必填) | 短信内容；含 `[尚未收到]` 表示未到 | 前端轮询调用 |
| `release` | 释放号码 | phone | 释放结果 | 失败跳过即可，勿重试 |
| `block` | 拉黑号码 | phone | 拉黑结果 | 失败跳过即可，勿重试 |
| `send` | 发短信 | phone、toPhone、content | 发送结果 | 仅限 1069 短信网关号 |
| `queryUsed` | 历史记录 | token | 换行符分隔的记录 | **限频：1 次/分钟，超频封 API** |

### 3.1 限频与容错策略（必须实现）

1. `queryUsed`：Rust 侧维护 `last_query_used_at` 时间戳，60 秒内重复调用直接返回本地缓存。
2. `getMsg` 轮询：由前端驱动，间隔 3 秒，总时长上限 120 秒，页面离开时停止。
3. 任何接口返回 `ERROR:` 前缀时，解析错误信息并转化为用户可读的中文提示，
   常见映射：
   - `token` 相关 → 「Token 无效，请到设置页重新粘贴」
   - `余额不足` → 「账户余额不足，请充值」+ 跳转充值链接按钮
   - 其他 → 原样展示

### 3.2 充值 / 注册链接

- 注册（含邀请码）：`https://www.d1jiema.com/appweb/signUp.html?inviter=1lngsgtr`
- 创建 Token：`https://www.d1jiema.com/appweb/signIn.html` → 个人中心 → 创建 API Token
- 充值：d1jiema 官网个人中心（软件内做外链跳转，不做内嵌支付）

## 4. 技术设计

### 4.1 总体架构

遵循现有模式：**Rust 后端命令（网络请求 + 状态） + zustand store（状态管理） + React 页面**。
不在前端直接请求 d1jiema API（避免 CORS 与 Token 暴露到渲染进程的网络面板）。

```
┌──────────────────────────────────────────────┐
│  前端                                          │
│  pages/RegisterAccount.tsx   注册账号一级导航页  │
│  store.ts 扩展 smsCode 状态切片                 │
│  types.ts 增加类型定义                          │
└───────────────┬──────────────────────────────┘
                │ Tauri invoke（snake_case 参数）
┌───────────────▼──────────────────────────────┐
│  Rust 后端                                     │
│  commands/sms_code.rs   全部命令 + 限频 + 脱敏  │
│  models.rs 增加 SmsCodeSettings               │
│  settings.json 持久化 token/keyword/cardType   │
└───────────────┬──────────────────────────────┘
                │ HTTPS GET（Rust 侧拼接 token）
        api.d1jiema.com/zc/data.php
```

### 4.2 Rust 端：`src-tauri/src/commands/sms_code.rs`（新建）

命令清单（全部注册到 `mod.rs` 的 `generate_handler!`）：

```rust
// 查询/保存接码设置（token 返回脱敏值，保存时若值为脱敏占位则不覆盖）
#[tauri::command] pub fn sms_code_get_settings(state: State<AppState>) -> SmsCodeSettings
#[tauri::command] pub fn sms_code_set_settings(state: State<AppState>, s: SmsCodeSettings) -> Result<(), String>

// 查询余额（缓存 30 秒，避免频繁请求）
#[tauri::command] pub async fn sms_code_balance(state: State<'_, AppState>) -> Result<f64, String>

// 取号（随机）；指定号：phone 参数可选
#[tauri::command] pub async fn sms_code_get_phone(state: State<'_, AppState>, phone: Option<String>) -> Result<String, String>

// 收短信（单次查询，前端负责轮询节奏）
#[tauri::command] pub async fn sms_code_get_msg(state: State<'_, AppState>, phone: String) -> Result<String, String>

// 释放 / 拉黑
#[tauri::command] pub async fn sms_code_release(state: State<'_, AppState>, phone: String) -> Result<String, String>
#[tauri::command] pub async fn sms_code_block(state: State<'_, AppState>, phone: String) -> Result<String, String>

// 发送短信
#[tauri::command] pub async fn sms_code_send(state: State<'_, AppState>, phone: String, to_phone: String, content: String) -> Result<String, String>

// 历史记录（服务端限频 1 次/分钟 + 本地缓存）
#[tauri::command] pub async fn sms_code_query_used(state: State<'_, AppState>) -> Result<Vec<String>, String>
```

内部实现要点：

- HTTP 客户端复用项目现有依赖（`reqwest`，检查 `Cargo.toml`，proxy.rs 已用过则直接用）。
- `d1jiema_get(code, params)` 私有函数统一拼接：
  `BASE?code={code}&token={token}&...`，参数逐一 URL 编码。
- 设置结构体（`models.rs`）：

```rust
#[derive(Serialize, Deserialize, Clone)]
#[serde(rename_all = "camelCase", default)]
pub struct SmsCodeSettings {
    pub token: String,          // 保存真实值，API 返回给前端时脱敏
    pub keyword: String,        // 默认 "Trae"
    pub card_type: String,      // 全部 | 实卡 | 虚卡，默认 "全部"
    pub province: String,       // 默认 ""（全部）
}
```

- 脱敏规则：`token` 回显为 `abcd****`（前 4 后 0）；前端提交时若值含 `****` 则跳过保存。

### 4.3 前端：`src/pages/RegisterAccount.tsx`（新建）

页面布局（单屏三区）：

```
┌────────────────────────────────────────────────┐
│ ① 顶部状态栏                                    │
│  [余额 ¥xx.xx]  [充值↗] [注册账号↗] [Token设置]  │
├────────────────────────────────────────────────┤
│ ② 手机号工作区                                  │
│  当前号码: 165********  [复制]                   │
│  [获取手机号] [指定号码…] [释放] [拉黑]           │
│  卡类型: (全部|实卡|虚卡)  关键词: [Trae]         │
├────────────────────────────────────────────────┤
│ ③ 短信区（Tab 切换）                             │
│  Tab1 收短信: 轮询进度条 + 短信内容 + [复制验证码] │
│      发送短信: 目标号码[1069…] 内容[____] [发送]  │
│  Tab2 短信记录: queryUsed 列表（显示缓存时间）     │
└────────────────────────────────────────────────┘
```

交互细节：

- **收短信轮询**：取号成功后自动开始（可在设置关闭自动轮询）；
  3 秒/次、上限 120 秒；收到内容后停止并用正则
  `/(?:验证码|code)[:：\s]*([0-9]{4,8})/i` 提取验证码，提供一键复制。
- **复制功能**：`navigator.clipboard.writeText()`，失败降级 `document.execCommand`。
- **验证码提取**：复制按钮提供两个——「复制验证码」「复制全文」。
- **释放/拉黑**：需二次确认（Confirm 弹窗）；失败 toast 提示「跳过即可」不重试。
- **指定号码**：弹窗输入 11 位手机号（正则校验 `^1\d{10}$`），调用 `getPhone?phone=`。

### 4.4 状态管理：`src/store.ts` 扩展

```ts
interface SmsCodeState {
  settings: SmsCodeSettings | null;
  balance: number | null;            // 余额（null=未查询）
  currentPhone: string | null;       // 当前持有的号码
  polling: boolean;                  // 是否正在轮询短信
  pollCountdown: number;             // 剩余轮询秒数（UI 倒计时）
  messages: string[];                // 收到的短信内容（本次会话）
  history: string[];                 // queryUsed 历史
  historyAt: number | null;          // 历史缓存时间戳
  smsCodeBusy: boolean;              // 防重复点击

  refreshSmsCodeSettings: () => Promise<void>;
  refreshSmsBalance: () => Promise<void>;
  fetchPhone: (phone?: string) => Promise<void>;
  pollMessage: () => Promise<void>;  // 单次拉取；轮询节奏放组件 useEffect
  releasePhone: () => Promise<void>;
  blockPhone: () => Promise<void>;
  sendSms: (toPhone: string, content: string) => Promise<void>;
  refreshHistory: () => Promise<void>;
}
```

## 7. 风险与限制

| 风险 | 应对 |
|---|---|
| d1jiema 改版 API | 全部请求收敛到 `d1jiema_get` 单函数，改一处即可 |
| queryUsed 超频封号 | Rust 侧硬限频（60s），前端按钮加冷却倒计时 |
| 号码被上一用户用过收不到码 | 文档化提示：收不到码先释放再取号，反复收不到用拉黑 |
| Token 泄露风险 | 仅存本地 settings.json；回显脱敏；日志脱敏 |
| 平台合规 | 免责声明：用户须遵守 d1jiema 及 Trae 服务条款，仅用于本人合法注册 |
